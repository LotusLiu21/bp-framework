## 1. 开篇：核心洞察

好故事的本质：投资人要的不是讲得动人，而是让人相信“沿着某条（新）路径越来越不可避免”。

本项目的好故事公式：

> **不可逆趋势** × **非你不可** × **风险递减路径**

---

## 2. 三大核心问题

### Q1：为什么一定会发生？（不可逆趋势）

- [ ] 为什么是现在？不早不晚的证据是什么？
- [ ] 一年前做太早、一年后做太晚的理由是什么？
- [ ] 成本 / 性能拐点、需求临界点、监管窗口、基础设施成熟度分别有哪些证据？

**标准叙事句式**：

> 当 [ X 的成本 / 性能 ] 达到 [ Y 临界点 ]，且 [ Z 基础设施 ] 普及后，[ A 用例 ] 首次具备商业成立性。

**本项目句式**：

> 当 [ \_\_\_\_\_\_ ] 达到 [ \_\_\_\_\_\_ ]，且 [ \_\_\_\_\_\_ ] 普及后，[ \_\_\_\_\_\_ ] 首次具备商业成立性。

---

### Q2：为什么是你来做？（非你不可）

- [ ] 你对行业的洞察比别人更早、更深，具体体现在哪里？
- [ ] 你的不对称优势是什么？（独家数据 / 渠道 / 网络 / 工程能力 / 课题定义权）
- [ ] 过往证据有哪些？（先行验证、客户背书、技术原型、人才磁场）
- [ ] 这不是履历堆砌，而是能力与问题的高度匹配——如何证明？

**叙事推演**：

1. 时代窗口已然打开
2. 你比别人看得更早更深
3. 掌握不可复制的独特资源
4. 偏偏你最有资格冲进去

---

### Q3：为什么风险会随时间下降？（去风险化路径）

| 阶段 | 目标 | 关键验证点（阈值 + 时间） |
|------|------|------------------------|
| 阶段一：技术可行性 | 产品能否实现 | |
| 阶段二：真实需求 | 是否有人真正需要 | |
| 阶段三：商业模式 | 是否具备正向 UE | |
| 阶段四：可复制扩张 | 能否规模化 | |

**关键认知**：Milestone 不是任务清单，而是投资人给“风险下降”定价的刻度尺。
